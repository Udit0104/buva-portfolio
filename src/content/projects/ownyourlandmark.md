# OwnYourLandmark — Real Estate Platform

OwnYourLandmark is a modern real estate platform designed to simplify property discovery and management. It enables users to explore properties, view detailed listings, interact with dynamic maps, and manage property-related information through a streamlined digital experience.

## 🚀 Key Features

- **Property Discovery & Search** — Search and filter property listings by location, price, property type, and available amenities.
- **Interactive Map Exploration** — Google Maps API integration providing location pins, landmark overlays, and distance-based search.
- **Detailed Property Listings** — Comprehensive property details including media galleries, features, pricing, and owner contact options.
- **Property Management Portal** — Dedicated management interface for property owners to publish, edit, and update real estate listings.
- **Real-Time Synchronization** — Built on Firebase for live database updates, user bookmarks, and authentication.
- **Responsive Interface** — Fully responsive design built with CSS and TypeScript for seamless desktop and mobile accessibility.

## 🛠️ Technical Highlights

- **Languages:** TypeScript, JavaScript, and CSS for a structured, type-safe, and responsive web architecture.
- **Backend & Database:** Firebase Firestore providing real-time property data syncing and listing management.
- **Location Services:** Google Maps API for interactive maps, custom location markers, and location routing.
- **API Architecture:** REST APIs handling property search indexing and inquiry data flows.
